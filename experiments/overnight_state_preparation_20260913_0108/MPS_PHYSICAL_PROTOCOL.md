# Frozen follow-up for the failed MPS overlap gate

This new engineering diagnostic preserves `mps-overlap` and its eight failed acceptance records. It neither changes the original tolerance nor trains a new optimizer. Known Adam roundoff sensitivity motivates separate identical-input and different-input tests. Success is not optimization superiority or authorization to scale.

The complete frozen four-target, replica-11 development panel is required, with original108 and structural_mean2_lbfgs endpoints, three saved updates and the same eight paths per update. All original source, protocol, summary, result, state, tensor and compressed split records are authenticated. The old immutable Adam function reconstructs both saved trajectories exactly. The original `mps_overlap` seed namespace, target identity, update index, path order, operators, sites and weights are regenerated and hash-checked; these are diagnostic streams, not final benchmark estimates.

For each saved dense pre-update vector, recompute the weighted dense and untruncated MPS gradients at identical theta, including individual path fidelities. Maximum gradient, loss, fidelity and path-fidelity errors must each be <=1e-10. At both saved post-update vectors, propagate dense and MPS output states on every path. The dense vector uses Qiskit's independently implemented statevector evolution; explicit reversed qargs convert YAQS local matrix ordering. Same-theta phase-aligned state distance, target-fidelity discrepancy and squared-norm error must each be <=1e-10. Record unaligned vectors and raw norms before normalization.

Let `delta_i` be the saved parameter difference. For each scalar Pauli-rotation occurrence, the generator norm is `abs(angle_scale)/2`. Only an initial single-qubit RZ acting on an untouched zero qubit can be removed as an exact global phase. All gate and noise supports are included in the touched-qubit proof. Shared occurrences are counted independently. The telescoping bound is `Btheta = sum_nongauge_occurrences(abs(angle_scale * delta_i))/2`. The different-theta phase-aligned distances, including independent dense/dense and MPS/MPS pairs and both crossed backend pairs, must be <= `Btheta + 2e-10`. The explicit allowance is two original same-theta numerical allowances; it is not a parameter tolerance. All raw parameter differences and bound terms are retained. Different-theta target-fidelity differences are reported against `2*Btheta + 4e-10`. No bound assumes that Gaussian or TFIM structural drift is entirely gauge.

Adam uses its unchanged alpha=.02, epsilon=1e-8 and fresh moments. At the first update, verify coordinatewise `abs(delta_theta) <= alpha/epsilon * abs(delta_gradient) + roundoff`. Subsequent updates use the exact bias-corrected first moments mD,mM and square-root second moments sD,sM: add `alpha*(abs(mD-mM)/(sD+epsilon) + abs(mM)*abs(sD-sM)/((sD+epsilon)*(sM+epsilon)))` to the preceding coordinate bound. The explicit subtraction allowance per step is `16*machine_epsilon*(1+abs(thetaD_before)+abs(thetaM_before)+abs(thetaD_after)+abs(thetaM_after))`. This engineering bound is reported separately from the unchanged original unconditional theta gate. Each scalar replay must reproduce the saved final theta and moments bit-for-bit.

Exact-zero discarded tails, zero hard-cap reductions, internal bond `<=2**floor(q/2)`, and norm error <=1e-10 remain required. Full gradient and forward split audits and all output vectors are saved in deterministic compressed JSON, with per-step signed checksums. Every forward output has its own path index, ordered map digest and weight. Path comparisons never sort by score.

There are 24 step units. Each complete unit makes two eight-path gradients (32 directions), eight additional dense pre-update forward scores, and four eight-path physical output replays (32 directions): 56 path calls and 72 directions. Derivative operations and actual tensor operations remain separate counters. Target input, factorization, regeneration, setup, failed/repeated work, compression and checkpoint I/O are charged in the outer case attempt; nested kernel timings are not additive. Preflight/source verification and final report serialization are engineering overhead outside case timers, explicitly unmeasured. Peak individual tensor storage is not process peak memory. Complete steps are reused on resume; a catchable interruption reruns only an incomplete step and charges both attempts. An uncatchable kill leaves unknown cost markers and blocks automatic resume rather than imputing zero. Completed output is authenticated and byte-preserving on resume.

Prepare-only freezes this protocol without numerical replay. Scientific execution is sequential and requires all numerical thread settings equal to one. The coordinator must run full lint and freeze the final sources before allocating one worker. No larger qubit count, extra optimization update, confirmation target or optimizer modification is included.
